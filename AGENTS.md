# AGENTS.md

## Purpose

This repository contains Harkamal Toor's personal Data Science portfolio.

## Version 1 architecture

- Python + Streamlit
- Three pages: Home, Projects, Contact
- Local profile image, CSS, and resume PDF
- `portfolio_data.py` is the content source
- No backend, database, analytics, paid services, or JavaScript framework
- Streamlit Community Cloud is the deployment target

## Page contract

### Home
Profile image, short professional headline, About Me story, personality keywords, compact technical skills, education line, and resume download.

### Projects
Six verified portfolio projects. Each project may expose a detail view, GitHub link, and live demo only when the URL is verified and publicly accessible.

### Contact
Verified public professional links. Do not invent or infer an email address.

## Content integrity

Never invent metrics, technologies, credentials, dates, employers, URLs, or results. Use only supplied or repository-verified material. If a public value is missing, omit it from the release UI rather than fabricating it.

## Design rules

Keep the interface simple and recruiter-friendly. Avoid dashboard aesthetics, gradients, progress bars, decorative charts, excessive animation, and unnecessary UI controls.

## Deployment boundary

Do not deploy or modify cloud settings without explicit user approval.
