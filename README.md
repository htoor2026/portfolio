# Harkamal Toor — Data Science Portfolio

A simple three-page Streamlit portfolio for Data Science, Machine Learning, experimentation, and applied AI work.

## Pages

- **Home** — profile photo, personal story, personality keywords, technical skills, and resume download.
- **Projects** — six portfolio projects with concise summaries, project details, GitHub links, and live demos when publicly available.
- **Contact** — LinkedIn, GitHub, X, and public email once approved.

## Tech stack

- Python 3.13
- Streamlit 1.65
- Local CSS and assets
- Streamlit Community Cloud target

## Run locally

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

## Deployment

The intended deployment target is Streamlit Community Cloud. Deployment should only happen after the public email, final visual QA, and link audit are complete.
