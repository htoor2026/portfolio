# Portfolio Website Specification

**Status:** Approved direction; implementation pending final QA

## Goal

Create a simple professional portfolio for Harkamal Toor focused on Data Science, Machine Learning, experimentation, and applied AI roles.

## Pages

1. **Home** — photo, About Me story, personality keywords, compact skills, education, resume download.
2. **Projects** — six project cards with project-detail views, GitHub links, and live demos when verified and public.
3. **Contact** — LinkedIn, GitHub, X, and approved public email.

## Requirements

- Python and Streamlit only.
- Streamlit Community Cloud target.
- Minimal professional light UI.
- Responsive layout.
- No backend, database, analytics, paid services, gradients, skill progress bars, or unnecessary animation.
- Project metrics stay on Projects, not Home.
- Resume is a local approved PDF downloaded from Home.
- Missing public information must be omitted rather than invented.
